# Практическая работа 3 — доска публикаций

Автор: Жуйкова Дарья Михайловна, группа БПИ-23-РП-1

## Запуск

Откройте `index.html` в браузере. Для запросов нужен интернет: страница обращается к JSONPlaceholder.

## Результаты проверки

- Кнопка «Загрузить публикации» получает пять записей с адресом `https://jsonplaceholder.typicode.com/posts?_limit=5`. На странице появляются заголовки и тексты, сообщение «Загружено публикаций: 5.».
- Пустая форма и поля из одних пробелов не отправляют запрос. Появляются сообщения «Укажите заголовок. Пробелы по краям не считаются.» и «Укажите текст публикации. Пробелы по краям не считаются.».
- Заголовок «Первая запись» и текст «Проверка создания публикации.» уходят методом POST. Сервер вернул ID 101. Запись появилась в начале списка, форма очистилась, показано сообщение об успехе.
- Временная замена адреса GET на `https://jsonplaceholder.typicode.com/postz` дала ошибку с кодом 404. Кнопка снова стала активной. В сданном `app.js` стоит исходный адрес.
